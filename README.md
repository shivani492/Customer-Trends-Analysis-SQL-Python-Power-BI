 # Customer Trends Analysis — SQL, Python & Power BI

An end-to-end customer behavior analysis project using **Python, MySQL, and Power BI** to understand customer purchasing patterns, spending behavior, product performance, and customer segments.

## 📌 Project Overview

This project follows a complete data analytics workflow:

**Data Cleaning → EDA → SQL Analysis → Power BI Dashboard → Business Insights**

### What I worked on

* Cleaned and explored customer data using **Python**
* Analysed customer behavior using **MySQL**
* Answered business questions using **SQL**
* Built an interactive **Power BI dashboard**
* Identified customer and purchasing trends
* Developed business recommendations based on the analysis

## 🛠️ Tools Used

* **Python** – Pandas, NumPy, Matplotlib, Seaborn
* **MySQL & SQL** – Data analysis and business questions
* **Power BI** – Data visualization and dashboard
* **Power Query & DAX** – Data transformation and calculations

## 🧮 SQL Business Questions

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which are the top 5 products with the highest average review rating?
4. How does average spending compare between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribed customers?
6. Which 5 products have the highest discount rate?
7. How many customers are New, Returning, or Loyal?
8. What are the top 3 most purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

## 📊 Power BI Dashboard

The dashboard focuses on:

* Customer demographics

* Product and category performance
* Customer segments
* Subscription behavior
* Discount usage

## 💡 Key Insights

The analysis was used to identify patterns in customer spending, purchasing behavior, product performance, and customer segments.
